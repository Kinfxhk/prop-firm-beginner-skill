# 居住地／地區資格（香港為例）

**通用流程跟從 `user_geo`（任何國家／地區）。** 香港只是例子。未取得用戶所報居住地前，不給「可用／可出金」結論。

1. 取得 `user_geo`（用戶自報即可）。
2. 開官方「restricted countries／eligibility」類頁，對照該居住地。
3. 一併閱讀 KYC／身份核實要求。
4. 答案標明「以用戶所報居住地＝X 為前提」；換地須重核。

盡力查路徑與 Failure template 見 `SKILL.md`；真的找不到公開資料才列已用方法與 URL，再寫「以上來源未見公開資料」。**禁止**教導改 IP、假地址或借帳戶繞過。
