# 「應否購買」決策樹 — 風險優先

## 風險披露（先讀）

- Prop firm 產品通常涉及**挑戰費／訂閱費**；多數情況下你可能**輸掉全部費用**。
- 帳戶資金多為**模擬資金**，並非你個人券商戶口；分潤／出金以各 firm 官方條款為準。
- **規則、價格、地區限制、出金政策會變更**；任何結論均須 runtime 開頁核實。
- 無人能保證你通過挑戰、獲利或成功出金。

**本 Skill 內容為非投資建議、非金融建議。** 不構成購買建議，亦不對任何 proprietary trading firm 作出推介或背書。

## 決策清單（自行核對）

1. 你能否接受**輸掉全部挑戰費／訂閱**？
2. 在已知 `user_geo` 下，產品線、地區資格、平台是否匹配（已開頁）？
3. 你是否已讀完（並開頁核實）DD／daily loss／禁止行為／罰則？
4. 出金方式、KYC、Live／真倉過渡政策，你是否接受？
5. 多帳戶／reset 成本是否在你可承受範圍（見 FAQ 23）？
6. 仍不確定 → **不要購買**；或僅視作學習預算。

## Agent 輸出限制

- **禁止**以「應該買 X」「一定要買 X」「最推薦唯一」「保證通過／保證出金」作答。
- **允許**：短名單＋條件對照＋開頁 Rule Cards；用語「可能適合／需自行核實」。
- 若使用追蹤／聯盟連結：每次 CTA 必須披露。
