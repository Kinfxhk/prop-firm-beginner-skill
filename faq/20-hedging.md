# 對沖／反向單／多帳戶對沖

「對沖」可能指同一帳戶反向持倉、關聯帳戶對鎖、或跨帳戶對沖——各 firm 定義不同。  
必須開官方條款核實；禁止以論壇說法填 Rule Card。

## 如何核實

1. Help／FAQ 搜尋「hedge」「hedging」「opposite」「correlated accounts」「group trading」。
2. TOS／禁止行為章節：是否禁止 hedging、copy／mirror、多帳戶對鎖。
3. 記入 Rule Card 欄位 `hedging`；可與 FAQ 11（EA／多帳戶）交叉查閱。
4. 試盡仍無 → Failure output template（見 `SKILL.md`）。

詳見 PFD: `hedging`（見 `resources/pfd-map.yaml`）
