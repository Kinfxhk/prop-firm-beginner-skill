# EA／跟單／多帳戶政策

EA、跟單、多帳戶等，多數寫於禁止行為／公平交易（fair trading）條款。  
違規後果（取消帳戶、沒收利潤等）必須以官方 TOS／Help 原文為準。  
本 Skill **不提供**「如何逃避偵測」的指引。

## 如何核實

1. Help／FAQ 搜尋「EA」「expert advisor」「copy trading」「multiple accounts」「prohibited」。
2. 開啟 TOS／規則 PDF 的 prohibited / restricted activity 章節。
3. 相關欄位可同時對照：`hedging`、`vpn_vps_multi_location_login`（見 FAQ 19、20）。
4. 記入 Rule Card；試盡仍無 → Failure output template（見 `SKILL.md`）。

詳見 PFD: `ea_copy_multi_account`（見 `resources/pfd-map.yaml`）
