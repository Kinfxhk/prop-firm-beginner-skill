# VPN／VPS／多地登入

部分 firm 限制 VPN、VPS、或多地／多裝置同時登入；條款常與公平交易、身份／地區規則相連。  
本 Skill **不教導**如何規避地區或登入限制。

## 如何核實

1. Help／FAQ 搜尋「VPN」「VPS」「IP」「multiple locations」「device」「login」。
2. TOS／規則 PDF：security、prohibited tools、geo／access 相關章節。
3. 記入 Rule Card 欄位 `vpn_vps_multi_location_login`：`url`＋`opened_at`＋`saw`。
4. 適用路徑試盡仍無 → Failure output template（見 `SKILL.md`）；結論「以上來源未見公開資料」。

詳見 PFD: `vpn_vps_login`（見 `resources/pfd-map.yaml`）
