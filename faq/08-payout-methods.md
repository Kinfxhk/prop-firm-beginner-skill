# 出金方式與地區限制

**先取得 `user_geo`（國家／地區，用戶自報即可）。** 未取得前，不給「可用／可出金」結論。

常見渠道如銀行、Wise、PayPal、加密等——**是否開放視居住地／KYC**，須對該 `user_geo` 開官方 payout／Help 頁核實。香港只是眾多地區之一，非唯一例子。答案須標明「以用戶所報居住地＝X 為前提」；換地須重核。

盡力查：官網 → Help／FAQ 搜尋 → TOS／規則 PDF → 結帳／定價相關頁。真的找不到公開資料 → 用 `SKILL.md` Failure template（列 `methods_tried`＋URL＋`opened_at`，再寫「以上來源未見公開資料」）。**禁止**教導規避地區限制。

詳見 PFD: `payout_methods`（見 `resources/pfd-map.yaml`）
