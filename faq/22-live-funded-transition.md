# Live Funded／真倉過渡

用戶常問：出金若干次後是否被迫轉 Live／真倉、各公司 Live 政策如何。**門檻日數、出金次數不得鎖定於本 Skill**；答案必須 runtime 開頁核實。

## 如何核實

1. Help／FAQ 搜尋關鍵字：`Live Funded`、`live account`、`payout limit`、`transition`、`sim to live`、`真倉`（若該站有中文）。
2. 開啟 TOS／規則 PDF 中與 funded／Live／payout 相關章節。
3. 查官方公告／狀態頁（若有）；優惠死線以外的規則仍以 Help／TOS 為準。
4. 若 Live 資格視居住地而定：須先有 `user_geo`，並標明「以用戶所報居住地＝X 為前提」；換地須重核。
5. 記入 Rule Card 欄位 `live_funded_transition`；試盡適用路徑仍無公開資料 → 用 `SKILL.md` Failure template（列 `methods_tried`＋URL＋`opened_at`，再寫「以上來源未見公開資料」）。**禁止發明門檻數字。**

出金次數與是否觸發 Live，亦見 FAQ 08。

詳見 PFD: `live_funded_transition`（見 `resources/pfd-map.yaml`）
