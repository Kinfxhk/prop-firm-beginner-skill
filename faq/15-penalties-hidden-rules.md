# 常見罰則／隱藏規則如何查

先讀完整 TOS／規則 PDF／Help；再查官方公告。  
論壇所謂「隱藏規則」最多標 **alleged** 並註明非官方；**不得**寫入已核實數字格。

## 罰則（只引官方）

Rule Card 欄位 `penalties` 只記錄官方後果用詞，例如：帳戶禁用、沒收利潤、帳戶作廢、強制平倉、拒絕出金等——**逐字對照**官網，禁止改寫誇大。

## 盡力核實路徑

1. 首頁 → Help／FAQ：「violation」「breach」「prohibited」「termination」。
2. TOS／規則 PDF：違規與終止章節。
3. 官方公告／狀態頁（若有規則變更說明）。
4. 試盡仍無公開條文 → Failure output template（`methods_tried`＋URLs＋「以上來源未見公開資料」）；禁止空口「未能核實」、禁止發明罰則。

詳見 PFD: `penalties_hidden_rules`（見 `resources/pfd-map.yaml`）
