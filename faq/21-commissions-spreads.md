# 交易佣金／點差／平台費

佣金、點差、平台費常分散於定價頁、平台說明與規則附錄；產品線（期貨 vs CFD）不可混表。  
FAQ **不預載**任何費率；數字必須 runtime 開頁。

## 如何核實

1. 定價／結帳頁：挑戰費以外是否列 commission、spread、platform fee。
2. Help／FAQ：「commission」「spread」「fees」「pricing」。
3. 平台或資料供應商文件（若官網有連）。
4. 記入 `commissions_spreads_fees`（與 FAQ 10 平台／資料費一併查亦可）。
5. 無公開表（期貨點差尤常見）→ Failure output template，結論「以上來源未見公開資料」；**禁止發明「零點差」等數字**。

詳見 PFD: `commissions_spreads`（見 `resources/pfd-map.yaml`）
